Easy Fiber Calc FTTH

Terakhir diperbarui: 21 Oktober 2026

1. Pendahuluan

Easy Fiber Calc FTTH adalah aplikasi untuk membantu pengguna menghitung estimasi redaman jaringan fiber optik dan membuat diagram jaringan FTTH. Kebijakan ini menjelaskan penanganan informasi saat aplikasi digunakan.

2. Data Proyek Lokal

Aplikasi menyediakan fitur penyimpanan proyek pada perangkat menggunakan database lokal. Informasi yang disimpan dapat mencakup nama proyek, susunan diagram, komponen jaringan, parameter redaman, panjang kabel, koneksi antarkomponen, dan nilai daya transmisi.

Pada versi ini, fitur proyek tidak menyediakan sinkronisasi ke server pengembang. Proyek dapat dihapus melalui aplikasi. Data lokal dapat hilang jika data aplikasi dihapus atau aplikasi di-uninstall.

3. Iklan dan Layanan Pihak Ketiga

Aplikasi menggunakan Google Mobile Ads untuk menampilkan iklan. Google dan mitra iklannya dapat memproses informasi tertentu, seperti alamat IP, pengenal perangkat atau iklan, interaksi iklan, dan data diagnostik atau pencegahan penipuan, sesuai konfigurasi layanan serta pilihan privasi pengguna.

Informasi lebih lanjut tersedia di Kebijakan Privasi Google .

4. Penggunaan Informasi

Data proyek lokal digunakan untuk menjalankan perhitungan, menampilkan dan memulihkan proyek tersimpan, serta menyediakan fitur aplikasi. Informasi yang diproses oleh layanan iklan digunakan sesuai fungsi dan kebijakan penyedia layanan tersebut.

5. Pembagian Informasi

Pengembang tidak menyediakan fitur untuk mengunggah data proyek lokal ke server pengembang. Layanan pihak ketiga, termasuk Google Mobile Ads, dapat memproses informasi sesuai kebijakan dan konfigurasi layanannya.

6. Keamanan dan Penyimpanan

Data proyek disimpan secara lokal pada perangkat. Pengguna disarankan menjaga keamanan perangkat dan tidak memasukkan informasi sensitif ke dalam nama atau isi proyek. Pengolahan data oleh pihak ketiga mengikuti kebijakan penyedia layanan terkait.

7. Privasi Anak

Aplikasi ini merupakan alat bantu teknis untuk jaringan fiber optik dan tidak dirancang khusus untuk anak-anak. Penetapan target audiens dan konfigurasi iklan akan mengikuti ketentuan yang berlaku.

8. Perubahan Kebijakan

Kebijakan ini dapat diperbarui apabila fitur aplikasi atau layanan pihak ketiga berubah. Versi terbaru akan dipublikasikan pada halaman ini.
